# 刷词英语小程序

一款供个人长期使用的微信原生小程序。通过上下滑动词卡，在例句中猜词、点查其他词，并在不同语境中再次遇到同一个词。完整的产品目标、需求、验收口径与实施顺序统一记录在 [PRD](docs/PRD/PRD.md)。

## 当前可运行版本

目前是已通过真机检查的交互样本，包含 12 个词义、24 张不同语境的词卡。已实现：

- 竖向滑动、未答上滑跳过、下滑回看及重新打开后续刷。
- 点击例句中的非目标词查看本句释义。
- 中文释义与英文近义词四选一；英文选项可先点词查义，再点右侧圆点作答。
- 原卡显示答案、当前词义和解释；首页可进入内容来源页。

样本按固定顺序播放，结束后可“再刷一轮”。目前没有完整 CET6/雅思词表、长期掌握统计、间隔复习、拼写或听写题、朗读音频和数据备份。更新内容前还需完成旧进度迁移；当前学习记录只保存在本机。

## 打开小程序

1. 在微信开发者工具中导入本目录作为小程序项目，使用自己的小程序 AppID 进行真机预览或上传。
2. 选择“编译”，进入词卡首页。小程序运行本身不需要后端或网络请求。
3. 如需使用本项目的自动化检查，先安装符合 `package.json` 要求的 Node.js 版本，再运行 `npm ci`。

也可以运行 `npm run build`，将通过校验的可导入项目生成到 `dist/miniprogram/`。该命令不代替微信开发者工具中的编译与真机检查。

## 开发与验证

| 命令 | 作用 |
| --- | --- |
| `npm run lint` | 检查 JavaScript 代码。 |
| `npm run build` | 校验内容、页面文件和语法，并生成 `dist/miniprogram/`。 |
| `npm test` | 运行单元测试。 |
| `npm run test:integration` | 构建后检查打包项目的答题、续刷、跳转与来源页。 |
| `npm run check` | 依次运行 Lint、构建、单元测试和集成测试。 |
| `npm run test:e2e` | 在配置好的微信开发者工具中自动操作词卡和来源页。 |

E2E 需要在开发者工具的「设置 → 安全设置」中开启服务端口，并允许 CLI 调用；CLI 不在默认位置时，可用 `MINIPROGRAM_CLI_PATH` 指定绝对路径。CI 运行 `npm run check`；E2E 需在已配置的本机环境执行。

建议在模拟器和真机核对点词、两种选择题、答题反馈、上下滑、重开续刷及内容来源页。样本中的第 1 张与第 13 张考同一词义，但使用不同例句；第 24 张后可重新开始。

## 后续产品方向

以[唯一 PRD](docs/PRD/PRD.md)为准：CET6 与雅思词表可单选或合并去重刷；为纳入词条制作全量可刷词卡；逐步加入选词补句、拼写、听辨和整句听写；用两次相隔至少 24 小时、不同例句中的独立正确听写判定“已掌握”；加入朗读、间隔复习、个人进度和备份恢复。题型按学习阶段交替安排，继续保留自由上滑、不设每日任务的体验。
