# 刷词英语小程序｜交互样本

这是微信原生小程序原型：12 个词义、24 张不同语境的词卡。句中点词、中文或英文四选一、答题反馈、上下滑、跳过与本机续刷均可体验。当前内容是样本，已有首轮内部检查，公开发布前仍需独立内容复核。

## 在微信开发者工具中打开

1. 导入本目录作为小程序项目。
2. 本地体验可使用项目中的测试 AppID 配置；如开发者工具要求，改填自己的小程序 AppID。上传或发布前必须换成自己的 AppID。
3. 编译后进入首页。点例句中的非目标词查看释义；中文题点整行作答，英文题点单词看释义、点右侧圆点作答。

小程序运行时无需安装 npm 包、无需后端和网络请求。开发与测试依赖使用 `npm ci` 安装。进度与最近 500 条原型交互事件保存在小程序本机缓存。当前没有事件上传与跨设备同步，因此不能用此版本做跨用户指标报表。

## 建议的体验检查

1. 在第 1 张卡点任意非目标词，应弹出本句释义；点高亮的目标词不应泄露答案。
2. 中文题点整行作答；到第 13 张卡后，英文题点选项单词看释义，点右侧圆点作答。
3. 在未答题时上滑，应直接进入下一张；下滑回看已答卡，答案应保留且不能再次提交。
4. 关闭并重新打开小程序，应从离开时的卡片继续。第 1 与第 13 张卡考同一个词义，但例句不同，中间有 11 张其他词卡。
5. 在第 24 张卡点“再刷一轮”，样本会重新开始。

- `npm run check` 可运行 Lint、构建、单元测试和集成测试。

## 开发与验证

建议使用 Node.js 22.13+（或 24+），先运行 `npm ci`。

| 命令 | 作用 |
| --- | --- |
| `npm run lint` | ESLint 检查 JavaScript。 |
| `npm run build` | 校验内容、页面文件、JSON 和 JS 语法，并生成可导入微信开发者工具的 `dist/miniprogram/`。这一步不代替开发者工具编译。 |
| `npm test` | 运行纯 Node 单元测试。 |
| `npm run test:integration` | 重新构建，并测试打包后的答题、续刷、跳转与来源页。 |
| `npm run check` | 顺序执行上述自动化检查，适用于本地和 GitHub CI。 |
| `npm run test:e2e` | 使用微信开发者工具自动化，实际操作词卡和来源页。 |

E2E 需要本机安装微信开发者工具，在「设置 → 安全设置」手动开启服务端口，并允许 CLI 调用。CLI 不在默认位置时，设置 `MINIPROGRAM_CLI_PATH` 为其绝对路径。服务端口是持久化的本机设置，用完可在开发者工具中关闭。GitHub CI 目前运行 `check` 所覆盖的检查；E2E 仍需在配置好的本机环境执行。
